### B. New findings, ordered by severity

1. **Blocker — portable restore can install archived configuration by accident.** **Plan:** §§5.1, 5.4, 10 step 7, 11 steps 3 and 6. **Evidence:** [plan:195](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:195), [plan:520](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:520), [plan:641](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:641). The target-declaration rule applies to “each snapshot member,” but built-in `stack/…`, `storage/…`, `sources/…`, and `workspaces/…` are not target-declared template members. The root tree contains `angee.yaml`; the unqualified files step then places restored files into targets even in default portable mode. **Fix:** define separate built-in member roles and an exact restore path map. In portable mode, read archived config and answers as metadata only; place them solely under `--restore-config`. Split the root-tree member or select its individual paths so data can be placed without placing config.

2. **Blocker — the restore journal cannot undo its first destructive writes.** **Plan:** §11 journal and steps 2–4. **Evidence:** [plan:620](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:620), [plan:643](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:643); existing Copier writes already have an in-memory rollback record in [template_plan.go:512](~/Work/angee-operator-stack-snapshots/internal/service/template_plan.go:512). The table says config-write undo restores from an aside, yet the pipeline writes config before moving asides, and its aside list does not include `angee.yaml` or the answers file. Using the *new* manifest to find owned paths can also miss paths owned under the old manifest. A newly created secret has no value in the safety snapshot for the stated `Set` undo. **Fix:** durably record old config and answers, their presence and guarded locations, and old and target path maps before any Copier or config write. Move the necessary old paths first; journal Copier’s complete file transaction. Record whether each secret previously existed, using backend `Delete` to undo an absent value.

3. **Blocker — the safety snapshot is not protected while restore is unfinished.** **Plan:** §§11–12. **Evidence:** [plan:613](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:613), [plan:637](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:637), [plan:689](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:689). Rollback depends on the safety snapshot through commit, but `forget --policy` selects manifests solely by restic’s retention result. After a crash, the root lock is free and policy forget can remove the safety snapshot before resume or rollback. **Fix:** have forget subtract exact IDs referenced by open restore journals from restic’s dry-run removal set. Refuse explicit forget of a referenced safety snapshot. Keep restic responsible for retention arithmetic.

4. **Major — claims are observations, not exclusive ownership.** **Plan:** §9 and §10 step 0. **Evidence:** [plan:450](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:450), [plan:481](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:481); S7 shows restic locks cover individual calls. Two roots can each read the old effective claim and write a newer one; an explicit takeover can likewise occur after a create’s initial check but before its manifest commit. “Two roots never share” is therefore stronger than this protocol proves. **Fix:** require external fencing of the former root before takeover, specify a total claim generation/order, and revalidate ownership before commit and each destructive repository call. If no owner-provided atomic claim operation is available, state the remaining race rather than treating a restic snapshot as a lease.

5. **Major — `--files-from-raw` conflicts with the live-copy and S13 confinement rules.** **Plan:** §10 steps 1 and 7. **Evidence:** [plan:492](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:492), [plan:526](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:526); S13. S13 proves restic stores links *inside a directory tree* as links, but follows a symlink in an argument’s ancestor. With individual file arguments such as `data/media/img/photo.jpg`, a writer mounted at `data/media` can replace `img`. If the hold test covers every file argument’s ancestors, that writer must be held and the promised unheld live copy cannot occur; if it checks only the top-level `data/media` argument, the escape remains. Pre/post inode checks do not catch a swap reversed during the read. **Fix:** specify directory-level restic arguments for live trees, with an exact post-copy path check, or require a frozen owner-provided tree. Define the hold test against the arguments restic actually opens.

6. **Major — format equality does not establish a usable target channel or empty target.** **Plan:** §§5.2–5.4 and 6. **Evidence:** [plan:202](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:202), [plan:314](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:314). One configuration can declare a format with `stream`, another with `files`, or use different required file names; the plan compares only the opaque string. The schema also permits `requires: running` or `stopped` with no `owns`, although §5.3 says moved-aside owned paths provide emptiness. D4 shows a repeat PostgreSQL restore into nonempty state fails. **Fix:** compare channel and exact file-name contract alongside format; require owned paths for hosted state unless a template reset/empty-state contract is explicitly supplied and journaled.

7. **Major — the proposed preflight `check` cannot run for a new hosted target as documented.** **Plan:** §§5.4, 11 preflight, 18. **Evidence:** [plan:226](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:226), [plan:599](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:599), [plan:908](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:908). The PostgreSQL check queries `psql … show server_version_num`, but `init --template` has no target server before configuration, secrets, and empty paths are created. The plan promises that *every* check passes before any target change. **Fix:** define a preflight check contract that can inspect the target image and archive without a running target, plus a separate post-start check when live server inspection is needed. Do not claim the latter is nondestructive preflight.

8. **Major — source member creation and v1 restore scope disagree.** **Plan:** §§5.5–5.6, 10 steps 7 and 10, 17 P7/P10. **Evidence:** [plan:243](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:243), [plan:525](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:525), [plan:668](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:668); [backups.go:692](~/Work/angee-operator-stack-snapshots/internal/service/backups.go:692). §5 says `sources/<id>` members record published revisions and remotes. §10 copies source stores “for bundle policy” before P10, while §11 refuses bundle sources and current `fetch_published` discovery returns evidence with no file tree. **Fix:** make v1 published-source evidence an explicit manifest record with no restic source member, and refuse bundle selection until P10. P10 can introduce its driver-owned member format and inverse.

9. **Major — raw archived answers can redirect a new template init.** **Plan:** §§4, 11 step 3, 17 P7. **Evidence:** [plan:645](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:645), [stack.go:45](~/Work/angee-operator-stack-snapshots/internal/service/stack.go:45), [stack.go:135](~/Work/angee-operator-stack-snapshots/internal/service/stack.go:135), [stack_update.go:670](~/Work/angee-operator-stack-snapshots/internal/service/stack_update.go:670). Archived answers can contain an old `ANGEE_ROOT` and `_src_path`. The current init computes the root from `ANGEE_ROOT`; passing old answers wholesale can select the old location or template. **Fix:** parse answers through the existing guarded reader, take only inputs declared by the *target* template, replace the recorded source path and root relation with the new target’s, then apply explicit `--input` values.

10. **Major — P0’s inventory omits dependencies it deletes and a verifier it promises to retain.** **Plan:** §§15 and 17 P0. **Evidence:** [plan:775](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:775), [backups.go:648](~/Work/angee-operator-stack-snapshots/internal/service/backups.go:648), [backups.go:1274](~/Work/angee-operator-stack-snapshots/internal/service/backups.go:1274), [api/types.go:200](~/Work/angee-operator-stack-snapshots/api/types.go:200), [service/vcs.go:26](~/Work/angee-operator-stack-snapshots/internal/service/vcs.go:26). The named files and symbols in §15 exist, including jj’s two misplaced-in-v2 symbols. But `verifyBackupSource` lives in the file marked deleted and depends on `backupSourceTrees` at lines 648–725, outside the specified moved ranges. Deleting `api/backups.go` also leaves `JobRunOperation.Artifact` and its clone typed as `BackupArtifact`; the VCS rename reaches `service/vcs.go`. GraphQL’s generated enum and resolver, `CauseBackupRequestConflict`, and remaining operator API documentation also reference the feature. **Fix:** expand P0 into an exact symbol-and-reference inventory. Move the source planner, its resource types, and verifier together; move `BackupSourceEvidence` into a surviving snapshot API file; remove the obsolete artifact field and its clone, error cause, generated GraphQL references, and all remaining published backup documentation in the same buildable change.

11. **Minor — P1 assigns save-only logging before a save role exists.** **Plan:** §§7 and 17 P1/P3. **Evidence:** [plan:377](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:377), [plan:844](~/Work/angee-operator-stack-snapshots/.agents/plans/stack-snapshots.md:844), [backend.go:158](~/Work/angee-operator-stack-snapshots/internal/runtime/backend.go:158).
